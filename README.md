# Práctica Git y GitHub: Clone, Fork y Pull Request

Este repositorio se utilizará para practicar un flujo básico de colaboración con Git y GitHub.

## Objetivo

Comprender y aplicar los conceptos de:

- Fork.  - OK
- Clone.  - OK
- Commit
- Push
- Pull Request
- Merge
- Sincronización con el repositorio original

## Flujo de trabajo

1. Hacer Fork de este repositorio.
2. Clonar el Fork en la computadora local.
3. Realizar cambios.
4. Crear un Commit.
5. Hacer Push al repositorio propio.
6. Crear un Pull Request.
7. Esperar la revisión y Merge.
8. Sincronizar el Fork con el repositorio original.
